======================================================
PROJECT PHOTOGRAPHS INSTRUCTIONS
======================================================

To add actual photographs of completed construction projects in Bhopal:

1. Drop your project photos in this folder:
   public/images/projects/

   Suggested naming conventions:
   - residential-villa-1.jpg
   - commercial-complex-1.jpg
   - rcc-foundation-1.jpg
   - civil-site-1.jpg

2. Open `src/data/projects.js` and update the `images` array for the project:
   images: [
     "/images/projects/residential-villa-1.jpg"
   ]
   and set `placeholder: false` once real photos are added.

3. The Project Gallery and Full-Screen Lightbox will automatically render them!
